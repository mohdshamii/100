How to use this repository

What the files actually tell you to do

The repository has no separate onboarding guide, so this is assembled from the notes and suggested-path sections written directly into Books.md and ResearchPaper.md.

Books.md

Start with math and classic ML

The suggested path opens with Section 1 (Math & Stats Foundations) alongside Section 2 (Classic Machine Learning) across months 1–2, then Sections 3–4 (deep learning foundations and practical engineering) in months 3–4.

Books.md

Pick a specialty, then go current

Months 5–6 are for choosing NLP (§5), computer vision (§6), or reinforcement learning (§7). Month 7 moves to generative AI and LLMs (§8), which the file flags as most relevant to current industry roles, before MLOps (§9) and theory (§10) from month 8 onward.

ResearchPaper.md

Read chronologically through the fundamentals

Weeks 1–3 cover Sections 1–3: classic foundations, CNN architectures, and the RNN/LSTM era — the historical build-up to modern deep learning.

ResearchPaper.md

Prioritize transformers and LLMs

Weeks 4–6 cover Sections 4–5 (attention, transformers, and large language models), which the file calls out as most relevant for AI/ML engineering roles today, before generative models, RL, self-supervision, and finally multimodal/safety work in weeks 7–12.

Both files

Links favor free, permanent sources

Books.md links to an author's official free version or open textbook where one exists; ResearchPaper.md links mostly to direct arXiv PDFs, noting that a handful of pre-2012 classics link to their original hosting page instead.

Both files

If a link breaks

Each file gives the same fallback: search the title and author (Books.md) or the title on Google Scholar (ResearchPaper.md) rather than assuming the resource is gone.

No contribution guide yet

The repository doesn't include a CONTRIBUTING.md, so there's no documented process to summarize here. The most reliable way to suggest a resource or flag a broken link is directly on GitHub.
