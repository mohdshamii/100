Structured Daily Study Routine

A rigorous, battle-tested time-blocked framework designed to maximize retention, hands-on implementation, and interview readiness across the 100 days.

The 4-Block Daily Learning Framework (120 Minutes)

To master Machine Learning, theory without code leads to illusion of competence, while code without theory leads to fragile debugging. This daily routine enforces the 70/30 Rule: 30% structured conceptual reading and 70% active problem solving, tensor tracing, and code implementation.

Block 1 30 Minutes

Theory & Concept Exploration

Build intuitive understanding of the core concept and understand why the algorithm was created.

  • 1 Read the primary GeeksforGeeks tutorial for high-level structure and architecture diagrams.
  • 2 Cross-check with TutorialsPoint or W3Schools for concise explanations and property tables.
  • 3 Answer the question: "What exact limitation of previous models does this approach solve?"
Output: Mental model and visual architecture diagram.
Block 2 25 Minutes

Math & Tensor Dimension Tracing

Demystify the underlying mathematics and verify tensor shapes through each layer.

  • 1 Deconstruct the day's key formula (e.g. Cross-Entropy loss, Attention scaling, Adam update).
  • 2 Trace matrix dimensions step-by-step on paper: verify input shapes, weights, and output tensors.
  • 3 Inspect gradients: understand which parameters receive gradients during backpropagation.
Output: Written mathematical formula and dimension verification.
Block 3 45 Minutes

Hands-On Code Implementation

Translate mathematical logic into executable, vectorized Python code.

  • 1 Open the Practice IDE or your local editor and implement the daily task from scratch.
  • 2 Avoid loops where vectorized NumPy or PyTorch tensor operations apply.
  • 3 Test edge cases: zero inputs, negative values, extreme floating point numbers, and shape mismatches.
Output: Working script with unit tests passed.
Block 4 20 Minutes

Active Recall & Personal Notes

Cement learning through immediate reflection and documentation.

  • 1 Write 3 concise bullet takeaways in the portal's Day Notes box without copying text.
  • 2 Review the related interview question in the Interview Q&A tab and answer it verbally.
  • 3 Commit code to your personal GitHub repository and check off the day as completed.
Output: Saved personal notes and GitHub commit.
Track A: Working Professional (90–120 Mins / Day) Part-Time

Designed for engineers, analysts, or students with full-time day jobs. Focuses on high-yield consistency.

07:00 - 07:35 Morning Block: Theory reading on GeeksforGeeks & formula breakdown
19:30 - 20:25 Evening Block: Hands-on coding challenge and PyTorch/NumPy implementation
20:25 - 20:45 Night Review: Write notes, answer interview question, commit to GitHub
Track B: Career Transitioner (3 Hours / Day) Full-Time

Designed for individuals dedicated full-time to landing an AI/ML engineering role within 3 to 6 months.

09:00 - 09:50 Deep Theory: Read GFG & TutorialsPoint, plus related research paper
10:00 - 10:40 Mathematical Derivation: Solve gradient equations and matrix shapes
11:00 - 12:15 Extended Coding: Complete daily practice task + build real mini-project
14:00 - 14:30 Documentation: Write technical blog summary or LinkedIn #100DaysOfCode post

Weekend Review & Milestone Consolidation (Every Saturday / Sunday)

Do not rush forward on weekends. Use Saturdays and Sundays to consolidate the 5 days completed during the week:

1. Full System Integration Combine the week's modules into a single clean pipeline or notebook.
2. Flashcard Self-Testing Test yourself on the week's formulas and interview questions without looking at solutions.
3. Benchmark Dataset Audit Train models on a standard Kaggle or Hugging Face dataset to verify generalizability.
