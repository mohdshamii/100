## How each list is organized

Both files follow the same structure:
- **10 topic sections**, ordered roughly beginner → advanced
- Each entry has title, author(s), and a link
- A suggested study path at the bottom (12 weeks for papers, 8 months for books)

## Suggested use

1. Start with the foundations sections in both files in parallel (math/classic ML papers + math/stats books)
2. Move into deep learning and transformers as your base solidifies
3. Branch into a specialty (NLP, CV, or RL) based on your target role
4. Finish with LLMs/generative AI and MLOps, since these map most directly to current AI/ML engineering job requirements

## Notes

- Paper links are primarily arXiv PDFs; a handful of pre-2013 classics (Perceptron, backprop, LeNet, AlexNet, LSTM) predate arXiv and link to their original hosting page instead.
- Book links prioritize free, legal versions (author sites, open textbooks) where they exist; otherwise they point to the publisher's page.
- If any link has moved, search the title + author — most of these are well-known, stable references.
